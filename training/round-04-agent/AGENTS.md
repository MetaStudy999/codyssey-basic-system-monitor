# B4-1 Round 04 Agent 작업 규칙

1. 새 미션 자료는 `training/round-04-agent/` 안에만 작성; 신규 소스는 `04-src/`만 사용.
2. 테스트는 `05-tests/`, 증빙은 `06-evidence/`, 평가는 `07-evaluation/`, 발표는 `08-presentation/`에 작성.
3. 기존 Round 01~03 및 루트 자료는 보존·참고만 허용. 승인 전 코드 생성·실행·배포·병합 금지.
4. 공식 요구사항 → 코드 → 실제 시험 → 증빙 → 판정 근거를 보존. 미확인은 NOT_VERIFIED.
5. 기존 Agent Codyssey MCP Core 4개 우선; 별도 권한 변경·운영 배포는 승인 필요.
