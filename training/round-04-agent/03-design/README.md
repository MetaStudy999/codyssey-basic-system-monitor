**명시적 전 미션 적용:** [중앙 의무 규정](https://github.com/MetaStudy999/codyssey-basic/blob/main/standards/ROUND-04-AGENT-MISSION-PROCESS-STANDARD.md)은 B1-1~B7-2 전 15개에 적용하며, 이 B4-1 미션도 생략할 수 없습니다. 해당 공식 PDF·평가 기준의 CORE/BONUS가 우선이고, 다른 미션의 기술 및 PASS는 자동 전이되지 않습니다.
