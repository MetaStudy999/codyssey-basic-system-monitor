## B. 기술 배우기 — 오늘은 한 개념만

### 오늘의 용어: 메트릭(Metric)

CPU 사용률·메모리 사용량처럼 상태를 수치로 표현한 것입니다. 자동차의 계기판처럼 현황 판단에 도움을 줍니다.

**그림으로 보기 (교육용 개념도):**

```mermaid
flowchart LR
 A["시스템 상태"] --> B["수치 측정·비교"]
 B --> C["현황 표시·알림"]
```

**생각할 질문:** CPU 사용률 수치 하나만으로 모든 장애 원인을 알 수 있을까요?

**답과 이유:** 아니요. 추이·로그·다른 지표를 함께 살펴봐야 합니다.
### 내 말로 설명·종이 재현 (Teach-back / Dry-run)

**두 문장으로 설명하기:** 측정 지표(Metric)는 CPU 사용률이나 메모리 사용량처럼 관찰 가능한 수치입니다. 한 시점의 숫자만으로 장애 원인이 확정되는 것은 아닙니다.

**종이에 흐름을 따라 그리기**
1. **입력:** CPU 사용률이 높다는 가상의 측정값 관찰.
2. **처리:** 여러 시점과 다른 자원·로그 비교.
3. **예상 결과:** 주의가 필요한지 판단할 추가 증거 제시.

**흔한 오해:** 측정치가 높다는 사실과 그 원인에 대한 판단은 구별해야 합니다.
